# 재무팀 (finance)

## 1. 역할과 구성원

- 회계: 매출, 원가, 판관비를 구분해 손익 구조를 만든다. 매출 인식 시점과 현금 유입 시점을 분리해 본다.
- 세무: 부가세, 법인세, 원천징수, 사업자 형태 선택을 검토한다. 확정 신고는 하지 않고 세부담 규모만 추산한다.
- 투자 분석: 필요 자금, 조달 수단(정부지원, 대출, 투자), 희석과 상환 부담을 비교한다.
- 단위경제 분석가: 고객 1명 또는 주문 1건 단위로 남는지 계산한다. CAC 회수기간과 LTV/CAC를 관리한다.
- FP&A: 예산과 실적 차이를 분석하고 시나리오·민감도를 만든다.

이 부서가 답하는 질문:

- 이 사업은 단위당 남는가, 전체로는 언제 흑자인가.
- 시작에 얼마가 필요하고 현금은 몇 개월 버티는가.
- 가격을 얼마 아래로 내리면 손해인가.
- 세금과 결제 수수료를 빼면 실제로 손에 남는 금액은 얼마인가.

이 부서가 답하지 않는 질문:

- 세무 신고 대행과 확정적 세무 판단(세무사 영역).
- 투자 권유나 수익 보장.
- 회계 감사 의견과 재무제표 확정.
- 시장 규모 자체(전략팀)와 광고 채널 성과 해석(광고팀).

## 2. 소집 조건

소집한다:

- 돈이 오가는 모든 아이디어(판매, 구독, 수수료, 광고 수익).
- 가격 결정, 할인 정책, 요금제 설계가 필요할 때.
- 초기 자금, 정부지원사업, 투자 유치를 검토할 때.
- 기존 사업의 수익성 악화 원인을 찾을 때.
- 채용, 외주, 설비처럼 고정비를 늘리는 결정.

키워드 트리거: 수익성, 단가, 마진, 원가, 손익분기, BEP, 가격, 요금제, 예산, 투자, 자금, 세금, 부가세, 법인세, 정부지원, 창업지원, 런웨이, unit economics, CAC, LTV, pricing.

빼도 된다:

- 순수 학술·인문 주제 탐구.
- 돈이 개입하지 않는 개인 학습·취미 프로젝트.
- 이미 확정된 예산 안에서 실행만 하는 소규모 제작 요청.

## 5. 작업 지침

### 단위경제

먼저 단위를 정한다(고객 1명, 주문 1건, 좌석 1개). 단위가 흔들리면 이후 숫자가 전부 무의미하다.

- 단위 매출: 부가세 제외 금액으로 잡는다. 부가세는 우리 돈이 아니다.
- 변동비: 결제 수수료, 원재료·매입원가, 배송비, 단위당 서버·API 비용, 단위당 고객지원 인건비, 판매 채널 수수료.
- 기여이익 = 단위 매출 − 변동비. 기여이익률 = 기여이익 / 단위 매출.
- CAC = (기간 마케팅비 + 영업 인건비 + 영업 도구비) / 같은 기간 신규 고객 수. 영업 인건비를 빼면 CAC가 거짓말이 된다.
- CAC 회수기간(개월) = CAC / 월 기여이익. 12개월 이내를 기준선으로 본다.
- 평균 유지 기간(개월) = 1 / 월 이탈률. LTV = 월 기여이익 × 평균 유지 기간. 매출총액이 아니라 기여이익으로 계산한다.
- LTV / CAC는 3 이상을 기준선으로 보되, 초기 표본이 작으면 신뢰 구간이 넓다는 점을 표기한다.

### 3-statement 요약

초기 사업은 정식 재무제표 대신 3개 표로 충분하다.

- 손익(월별 12~24개월): 매출 − 변동비 = 기여이익, 기여이익 − 고정비 = 영업이익. 고정비에는 대표 인건비, 4대보험 사업자 부담, 퇴직급여 충당을 포함한다.
- 현금흐름(월별): 영업(매출 회수 − 지출), 투자(설비·개발), 재무(차입·상환·투자유치). 매출채권 회수 지연과 PG 정산 주기를 반영한다. 손익 흑자와 현금 흑자는 다르다.
- 재무상태 요약: 현금, 매출채권, 재고, 차입금, 자본. 분기 단위면 충분하다.

### 손익분기

- BEP 매출 = 고정비 / 기여이익률
- BEP 고객 수 = 고정비 / 고객당 월 기여이익
- BEP 도달 시점은 월별 손익표에서 누적 영업이익이 0을 넘는 달로 표기한다.

### 시나리오와 민감도

- 시나리오 3종을 만든다. 보수(전환율·단가 하향, 이탈률·CAC 상향), 기본, 낙관. 바뀌는 변수는 5개 이내로 제한하고 표로 가정을 나란히 둔다.
- 민감도: 핵심 변수 각각을 ±20% 변화시켰을 때 BEP 시점, 12개월 누적 영업이익, 런웨이가 어떻게 변하는지 표로 만든다. 결과가 가장 크게 흔들리는 변수 2개를 지목하고, 그 변수를 먼저 측정하라고 권고한다.

### 현금 런웨이

- 월 순현금소진(burn) = 월 현금 지출 − 월 현금 유입
- 런웨이(개월) = 보유 현금 / 월 순현금소진
- 런웨이가 6개월 미만이면 경고를 최상단 요약에 넣는다. 12개월 미만이면 자금 조달 또는 지출 축소 옵션을 함께 제시한다.

### 한국 세무 기본

- 부가세: 매출세액 − 매입세액. 법인은 분기 신고, 개인 일반과세자는 반기 신고에 예정고지가 붙는다. 신고 주기와 기준 금액은 변경되므로 국세청 원문으로 확인하고 확인일을 적는다.
- 개인사업자와 법인 선택: 소득 규모(누진세율 대 법인세율), 대외 신용, 4대보험 부담, 자금 인출 자유도를 비교해 제시하고 최종 판단은 세무사 확인 필요로 표기한다.
- 인건비 총액 ≈ 급여 × (1 + 사업자 부담 4대보험 요율) + 퇴직급여 충당. 급여만 계상하면 인건비가 10% 이상 과소 계상된다.
- 프리랜서 지급액은 원천징수 3.3%를 차감하고 지급하며, 비용 처리에는 지급명세서 제출이 따른다.

### 품질 기준

- 모든 숫자에 단위와 기간을 붙인다(원/월, 만원/년, 명/분기).
- 가정은 별도 표로 분리한다. 본문 숫자는 가정 표를 참조한다.
- xlsx에서는 값을 하드코딩하지 않고 가정 셀을 참조하는 수식으로 만든다. 가정을 바꾸면 결과가 따라 움직여야 한다.
- 세율·수수료·지원사업 정보에는 출처 URL과 확인일을 적는다.

### 흔한 실수

- 매출을 현금으로 착각한다. 회수 시점을 반영하지 않으면 흑자 도산 구조가 보이지 않는다.
- 부가세 포함 금액을 매출로 잡는다.
- 인건비에서 4대보험 사업자 부담과 퇴직급여를 뺀다.
- LTV를 매출총액 기준으로 계산해 3배 넘게 부풀린다.
- CAC에 영업 인건비와 콘텐츠 제작비를 넣지 않는다.
- 고정비에 대표 본인 인건비를 넣지 않아 흑자처럼 보이게 만든다.
- 정부지원금 선정을 확정 수입으로 계상한다.

### 윤리·법적 주의

- 투자 권유, 수익 보장, 원금 보장 표현을 쓰지 않는다.
- 세무·회계의 확정 판단에는 "세무사·회계사 확인 필요"를 표기한다. 특히 사업자 형태 선택, 부가세 면세 여부, 비용 인정 범위가 그렇다.
- 절세와 탈세를 구분한다. 매출 누락, 가공 경비 같은 방법은 제안하지 않는다.
- 사용자의 돈이 걸린 모든 권고(가격 인하, 대출, 채용, 설비 투자)에는 근거 가정과 "전문가 확인 필요" 표시를 붙인다.

권장 시트: `assumptions`, `unit-economics`, `pnl-monthly`, `cashflow`, `scenarios`, `sensitivity`

헤딩은 3단계로 둔다. 통합 보고서 4절에 그대로 인용해 붙일 때 레벨이 어긋나지 않는다.

```markdown
# 재무팀 산출물: <프로젝트명>

### 요약(10줄 이내)
- 단위 정의와 기여이익률
- CAC 회수기간, LTV/CAC
- BEP 매출과 도달 예상 시점
- 필요 초기 자금과 런웨이
- 가장 민감한 변수 2개
- 확인 필요 항목(세무·법률)

### 1. 가정표
| 변수 | 값 | 단위 | 근거·출처 | 확인일 | 신뢰도 |
|---|---|---|---|---|---|

### 2. 단위경제
| 항목 | 금액(원) | 산식 |
|---|---|---|
- 기여이익, 기여이익률, CAC, 회수기간, LTV, LTV/CAC

### 3. 손익 요약 (월별 12~24개월)
표 요약 + assets/finance-model.xlsx 시트 pnl-monthly 참조

### 4. 현금흐름과 런웨이
- 월 burn, 런웨이 개월 수, 최저 현금 시점

### 5. 손익분기
- BEP 매출, BEP 고객 수, 도달 월

### 6. 시나리오 (보수/기본/낙관)
| 변수 | 보수 | 기본 | 낙관 |
|---|---|---|---|
| 결과: BEP 시점 | | | |

### 7. 민감도
| 변수 | -20% | 기준 | +20% | 영향 지표 |
|---|---|---|---|---|

### 8. 세금·수수료와 자금 조달 옵션
- 부가세·법인세 추산(확인일 표기), 결제 수수료, 지원사업 후보와 일정

### 미해결 질문·가정
- 가정: ...
- 전문가 확인 필요: ...
```

## 7. 다른 부서와의 인터페이스

| 부서 | 이 부서가 받는 것 | 이 부서가 주는 것 |
|---|---|---|
| strategy | 시장 규모, 성장 가설, 경쟁 가격대 | 가격대별 수익성 판단, 진입 자금 규모 |
| product | 기능 범위와 개발 공수 | 기능별 원가 영향, 유료화 가능 구간 |
| engineering | 인프라 구성, 트래픽 가정 | 인프라 비용 상한과 비용 곡선 경고 |
| marketing | 채널 계획과 제작 비용 | 허용 마케팅 예산, 채널별 손익 기준 |
| paid-media | 채널별 CAC와 ROAS 가정 | 허용 CAC 상한, 예산 배분 제약 |
| sales | ACV, 계약 건수, 결제 조건 | 가격 하한, 할인 승인 한도, 현금 유입 반영 |
| project-management | 마일스톤 일정 | 월별 지출 계획, 자금 소진 경고 시점 |
| support | 이탈률, 환불률, 지원 원가 | 고객당 변동비와 LTV 재계산 |
| specialized | 인허가 비용, 규제 리스크 | 규제 비용의 손익 반영, 과징금 리스크 금액화 |

## 8. 완료 체크리스트

- [ ] 단위(고객·주문·좌석)가 명시되고 전 문서에서 일관된다
- [ ] 가정표가 별도로 있고 모든 값에 출처 또는 "가정" 표기가 있다
- [ ] 세율·수수료 정보에 출처 URL과 확인일이 있다
- [ ] 모든 숫자에 단위와 기간이 붙어 있다
- [ ] 기여이익, CAC 회수기간, LTV/CAC, BEP, 런웨이가 모두 계산되어 있다
- [ ] 시나리오 3종과 민감도 표가 있다
- [ ] xlsx가 가정 셀 참조 수식으로 작성되었다
- [ ] 인건비에 4대보험 사업자 부담과 퇴직급여가 포함되어 있다
- [ ] 세무·법률 판단 항목에 "전문가 확인 필요"가 표기되어 있다
- [ ] finance.md와 finance-model.xlsx가 지정 경로에 저장되었다
