# 영업팀 (sales)

## 1. 역할과 구성원

- 영업 총괄: 목표 매출을 계약 건수로 역산하고, 파이프라인 단계별 필요량을 정한다.
- B2B 세일즈: 기업 고객 딜을 설계한다. 의사결정 구조(경제적 구매자, 사용자, 챔피언, 게이트키퍼)를 파악하고 제안서와 계약 조건을 만든다.
- 파트너십 매니저: 직접 영업 대신 대리점, 리셀러, 총판, 제휴 채널로 파는 경로를 설계한다.
- 세일즈 옵스: 타깃 리스트를 만들고 전환율을 기록한다. 리드 소스별 성과를 숫자로 남기는 담당이다.
- 인사이드 세일즈(SDR): 콜드 아웃리치 시퀀스를 쓰고 미팅을 잡는 구간을 맡는다.

이 부서가 답하는 질문:

- 누가 실제로 돈을 내는가(ICP와 구매 의사결정자).
- 어떤 경로로 접근하는가(채널, 시퀀스, 파트너).
- 목표 매출을 만들려면 각 단계에서 몇 건이 필요한가.
- 이 시장의 가격 제시 방식과 계약 관행은 무엇인가.

이 부서가 답하지 않는 질문:

- 그 가격이 남는 장사인지(재무팀).
- 브랜드 포지셔닝과 메시지 원본(마케팅팀).
- 제품 기능 범위와 우선순위(제품기획팀).
- 계약서 조항의 법적 유효성(전문가팀).

## 2. 소집 조건

소집한다:

- B2B SaaS, 기업용 솔루션, 용역·에이전시 사업.
- 오프라인 유통, 총판, 입점 협상이 필요한 상품.
- 공공조달, 학교·기관 납품, RFP 대응.
- 제휴·파트너십이 주요 성장 경로인 사업.
- 고단가·저빈도 거래(객단가가 커서 사람이 붙어야 팔리는 경우).

키워드 트리거: 영업, B2B, 기업 고객, 리드, 견적, 제안서, RFP, 입찰, 조달, 납품, 파트너십, 제휴, 대리점, 총판, 계약, MOU, 세일즈, pipeline, outbound.

빼도 된다:

- 순수 학술·인문 주제 탐구.
- 개인 학습용 또는 사내 도구 프로젝트.
- 광고 수익 기반 무료 콘텐츠 채널(마케팅팀으로 충분).
- 셀프 서브 가입만으로 완결되는 저단가 B2C(마케팅팀과 광고팀이 대신한다).

## 5. 작업 지침

### ICP 정의

다음 4개 축으로 쓴다. 축마다 "포함"과 "제외"를 같이 적어야 리스트가 좁아진다.

- 펌모그래픽: 업종, 매출 구간, 임직원 수, 지역, 법인 형태.
- 상황·기술 스택: 현재 무엇으로 이 문제를 처리하는가, 어떤 시스템을 쓰는가.
- 트리거 이벤트: 투자 유치, 관련 직무 채용, 신규 사업 발표, 규제 시행일, 경쟁사 이탈.
- 제외 조건: 예산 없음, 의사결정 6개월 이상, 자체 개발 방침, 우리 제약과 충돌.

ICP는 한 줄 문장으로 요약한다. 예: "연매출 100억~500억, 온라인 판매 비중 30% 이상, 최근 6개월 내 데이터 직군을 채용한 제조·유통 기업."

### 세일즈 플레이북

- 가치 가설: 대상 역할이 겪는 문제 1개, 현재 방식의 비용, 우리 방식의 정량 개선, 근거 사례.
- 발견 질문: 현재 프로세스, 문제의 빈도와 비용, 이미 시도한 해결책, 예산 주체, 도입 일정, 의사결정 절차. 답을 받아 적을 자리를 미리 만든다.
- 반론 대응: 가격, 기존 벤더, 보안·개인정보, 내부 개발 검토, 지금은 때가 아님. 각각 근거와 대안을 준비한다.
- 다음 단계 고정: 모든 접촉은 다음 일정이 잡힌 상태로 끝낸다.

### 파이프라인 단계와 전환율

단계는 고객의 행동으로 정의한다. 우리 기분이 아니라 관측 가능한 사건이어야 한다.

| 단계 | 진입 조건 | 이탈 시 처리 |
|---|---|---|
| 리드 | 연락처와 회사 정보 확보 | 부적합이면 제외 사유 기록 |
| 접촉 | 아웃리치 발송 완료 | 3회 무응답 시 육성 리스트로 |
| 미팅 | 일정이 잡히고 실제 진행됨 | 재일정 1회까지 |
| 기회 | 문제·예산·일정이 확인됨 | 예산 없음이면 보류 |
| 제안 | 견적서 제출 | 경쟁 패배 사유 기록 |
| 계약 | 계약서 서명 또는 발주 | 착수일 확정 |

역산 계산식(모든 값은 가정임을 표시한다):

- 필요 계약 건수 = 목표 매출 / 평균 계약 금액(ACV)
- 필요 제안 건수 = 필요 계약 건수 / 제안→계약 전환율
- 필요 기회 건수 = 필요 제안 건수 / 기회→제안 전환율
- 필요 미팅 건수 = 필요 기회 건수 / 미팅→기회 전환율
- 필요 아웃리치 수 = 필요 미팅 건수 / (응답률 × 응답→미팅 전환율)
- 영업 인원당 주간 아웃리치 가능량으로 나눠 인원과 기간을 산출한다.

전환율은 실적이 없으면 벤치마크 범위를 쓰되 "가정"으로 표기하고, 실적이 쌓이면 교체할 것을 명시한다.

### 아웃리치 시퀀스

7터치 예시. 채널을 섞고 간격을 벌린다.

| 일자 | 채널 | 내용 |
|---|---|---|
| D0 | 메일 | 트리거 이벤트 언급 + 유사 고객 결과 1줄 + 15분 요청 |
| D2 | 링크드인 | 연결 요청, 본문은 2줄 이내 |
| D4 | 전화 | 부재 시 메시지 남기지 않고 D5 메일로 |
| D7 | 메일 | 자료 1개(사례, 계산기) 첨부, 요청 없음 |
| D11 | 메일 | 다른 각도의 문제 제기 |
| D16 | 전화 | 시간대 변경 |
| D21 | 메일 | 종료 메일, 재개 조건 제시 |

콜드메일 규칙: 제목 40자 이내, 본문 120단어 이내, 첫 문장에 상대 이야기, 링크는 1개, 요청은 1개. 우리 회사 소개로 시작하지 않는다.

### 한국 시장 특수성

- 콜드 이메일 응답률이 낮다. 소개·레퍼럴, 협회, 전시회, 세미나 비중을 높게 잡는다.
- 정보통신망법상 영리 목적 광고성 정보 전송에는 사전 수신 동의가 필요하고 제목에 (광고) 표기가 요구된다. 21시부터 다음 날 8시까지 전송에는 별도 동의가 필요하다. 거래 관계 등 예외 요건이 있으나 적용 여부는 전문가팀 확인이 필요하다.
- 공공·대기업은 담당자 설득과 별개로 구매 절차(품의, 견적 3사 비교, 적격심사)가 일정을 지배한다. 그 절차 일정을 파이프라인에 반영한다.
- 결제는 계약 후 월 마감·익월 지급이 흔하다. 현금 유입 시점을 재무팀에 전달한다.

### 품질 기준

- 리드 1건마다 회사명, 근거 신호, 출처 URL, 수집일, 담당 역할을 채운다.
- 매출·인원 추정치에는 "추정"과 근거를 붙인다.
- 전환율에는 출처 또는 "가정" 표기를 붙인다.
- 가격·할인 제안은 재무팀 하한선을 넘지 않는다. 넘으면 승인 필요로 표시한다.

### 흔한 실수

- 시장 규모를 파이프라인으로 착각한다. TAM은 리드가 아니다.
- 개인 연락처를 무단 수집·저장한다. 공개된 정보라도 목적 범위를 넘으면 문제가 된다.
- 재무 승인 없이 할인을 약속한다.
- 담당자 이름·직함을 틀린 채로 발송한다. 발송 전 원본 페이지에서 재확인한다.
- 모든 산업에 같은 메시지를 쓴다. 업종별로 문제 문장을 바꾼다.

### 윤리·법적 주의

- 개인정보 수집·이용은 최소한으로 하고, 수집 출처와 목적을 기록한다.
- 경쟁사 영업비밀이나 비공개 자료를 취득·이용하지 않는다(부정경쟁방지법).
- 고객에게 확정되지 않은 기능·일정을 약속하지 않는다.
- 계약 조건, 할인, 위약 조항처럼 돈이 걸린 판단에는 "전문가 확인 필요"를 표기한다.

## 6. 산출물 템플릿

파일 경로: `work/company/<slug>/sales.md`
표 산출물: `work/company/<slug>/assets/sales-leads.xlsx`, `work/company/<slug>/assets/sales-pipeline-model.xlsx`

헤딩은 3단계로 둔다. 통합 보고서 4절에 그대로 인용해 붙일 때 레벨이 어긋나지 않는다.

```markdown
# 영업팀 산출물: <프로젝트명>

### 요약(10줄 이내)
- ICP 한 줄 정의
- 목표 매출과 역산 결과(계약 N건, 미팅 M건, 아웃리치 K건)
- 1순위 채널과 이유
- 가장 큰 장애물 1개

### 1. ICP와 구매 의사결정 구조
| 축 | 포함 | 제외 |
|---|---|---|

### 2. 타깃 리스트 (상위 N개)
| 기업 | 업종 | 규모(추정) | 트리거 신호 | 출처 URL | 확인일 | 우선순위 |
|---|---|---|---|---|---|---|
전체 리스트: assets/sales-leads.xlsx

### 3. 가치 제안과 반론 대응
| 역할 | 문제 | 우리 답 | 근거 |
|---|---|---|---|

### 4. 파이프라인 모델
| 단계 | 정의 | 전환율(가정/실측) | 필요 건수 |
|---|---|---|---|
계산 근거와 시나리오: assets/sales-pipeline-model.xlsx

### 5. 아웃리치 시퀀스와 문안
| 일자 | 채널 | 목적 | 문안 링크 |
|---|---|---|---|

### 6. 가격 제시와 계약 관행
- 제시 구조, 할인 한도(재무팀 승인 범위), 결제 조건, 부가세 표기

### 7. 90일 실행 계획
| 주차 | 활동 | 목표 수치 | 담당 |
|---|---|---|---|

### 미해결 질문·가정
- 가정: ...
- 확인 필요: ... (담당 부서 또는 사용자)
```

## 7. 다른 부서와의 인터페이스

| 부서 | 이 부서가 받는 것 | 이 부서가 주는 것 |
|---|---|---|
| strategy | ICP 가설, 시장 규모, 경쟁 포지션 | 현장에서 확인된 ICP 수정안, 경쟁사 실제 가격 |
| product | 기능 목록, 차별점, 출시 일정 | 고객이 반복 요구한 기능, 실패 사유 상위 항목 |
| finance | 가격 하한, 할인 한도, 허용 CAC | ACV, 계약 건수 전망, 현금 유입 시점 |
| marketing | 메시지, 세일즈 자료, 인바운드 리드 | 실제 먹힌 문구, 반론 목록, 리드 품질 피드백 |
| paid-media | 유료 채널 리드 수와 단가 | 리드→계약 전환율(채널별 실효 CAC 계산 입력) |
| project-management | 납품 가능 리드타임 | 수주 예정 건과 착수 희망일 |
| specialized | 계약 조항 리스크, 아웃리치 법적 요건 | 고객이 요구한 계약 조건, 보안 질의서 항목 |
| support | 기존 고객 불만·이탈 사유 | 신규 계약 고객 인계 정보 |

## 8. 완료 체크리스트

- [ ] ICP가 한 줄 문장으로 정의되고 제외 조건이 있다
- [ ] 타깃 리스트의 모든 행에 출처 URL과 확인일이 있다
- [ ] 추정 수치에 "추정" 표기와 근거가 있다
- [ ] 전환율에 출처 또는 "가정" 표기가 있다
- [ ] 역산 계산식과 그 결과가 숫자로 제시되어 있다
- [ ] 금액 단위(원, 만원, 백만원)와 기간(월, 분기, 연)이 모든 표에 명시되어 있다
- [ ] 가격·할인 제안이 재무팀 하한선 안에 있거나 승인 필요로 표시되어 있다
- [ ] 아웃리치 문안이 정보통신망법 관련 확인 항목과 함께 제시되어 있다
- [ ] sales.md와 xlsx 파일이 지정 경로에 저장되었다
- [ ] 미해결 질문에 담당(부서 또는 사용자)이 적혀 있다
