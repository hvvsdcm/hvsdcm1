# 마케팅팀 (marketing)

## 1. 역할과 구성원

- 콘텐츠 마케터: 콘텐츠 필러와 제작 계획을 짜고 실제 원고를 쓴다.
- SEO 담당: 키워드 조사, 클러스터 설계, 온페이지 개선안을 만든다.
- SNS 전략가: 채널별 포맷과 게시 리듬, 커뮤니티 대응 원칙을 정한다.
- 브랜드 보이스 담당: 톤을 형용사 3개로 고정하고 문장 규칙과 금지 표현을 정한다.
- CRM·이메일 담당(겸임): 가입 후 시퀀스와 재방문 유도 메시지를 설계한다.

이 부서가 답하는 질문:

- 무엇을 어디에 어떤 말로 알리는가(메시지, 채널, 포맷).
- 검색에서 어떤 키워드로 잡히는가, 어떤 콘텐츠를 몇 개 만들어야 하는가.
- 브랜드가 어떤 말투로 말하는가, 무엇을 말하지 않는가.
- 유기적 채널로 초기 사용자를 어떻게 데려오는가.

이 부서가 답하지 않는 질문:

- 유료 광고 예산 배분과 입찰(광고팀).
- 제품 기능과 우선순위(제품기획팀).
- 시각 아이덴티티와 화면 디자인(디자인팀). 카피와 메시지까지 담당한다.
- B2B 개별 딜 진행(영업팀).

## 2. 소집 조건

Wave 2에서 포지셔닝·메시지, Wave 3에서 실제 콘텐츠를 만든다. 사람에게 알려야 하는 결과물이면 소집한다.

소집 트리거 키워드:

- 한국어: 마케팅, 홍보, 콘텐츠, 블로그, SEO, 검색 노출, 인스타, 유튜브, 뉴스레터, 런칭, 브랜딩, 카피
- 영어: marketing, content, SEO, keyword, social, newsletter, launch, campaign, copywriting, brand voice

빼도 되는 경우:

- 내부 도구, 사내 시스템처럼 외부 홍보가 없는 과제.
- 순수 학술·조사 과제.
- 이미 확정된 메시지로 광고 집행만 남은 경우(광고팀 단독).

## 3. 수집해야 할 정보

### 3.1 사용자·저장소에서 (내부)

- [ ] 제품이 해결하는 문제와 사용자가 쓰는 실제 표현
- [ ] 기존 채널 자산: 블로그, 인스타, 유튜브, 뉴스레터 구독자 수와 최근 성과
- [ ] 기존 콘텐츠 목록과 성과 상위·하위 글
- [ ] 브랜드 자산: 로고, 컬러, 기존 슬로건, 금지 표현
- [ ] 저장소 안 공개 페이지 구조(정적 사이트라면 URL 구조, 메타 태그, sitemap 유무)
- [ ] 제작 리소스: 글쓰기 가능 인원, 영상 제작 가능 여부, 주당 투입 시간
- [ ] 규제·심의 대상 여부(건강기능식품, 의료, 금융, 교육 광고는 별도 규정이 있다)
- [ ] 사용자가 쓰기 싫어하는 표현이나 채널

### 3.2 웹·외부 소스에서 (외부)

- [ ] 네이버 검색광고 키워드도구: 월간 검색량(PC/모바일 분리), 연관 키워드, 경쟁 정도
- [ ] 구글 키워드플래너: 월 검색량 범위와 계절성, 영어권 키워드 비교
- [ ] 네이버 데이터랩, 구글 트렌드: 검색 추세와 급상승 연관어, 연령·성별 분포
- [ ] 경쟁사 콘텐츠: 블로그 최근 20편의 주제·형식·길이, 어떤 글이 검색 상위에 있는지
- [ ] 경쟁사 SNS 채널: 인스타그램·유튜브·스레드·X의 게시 빈도, 평균 반응, 잘 되는 포맷
- [ ] 검색 결과 화면(SERP) 관찰: 상위 10개가 블로그인지 카페인지 유튜브인지, 지식iN 노출 여부
- [ ] 커뮤니티 언어: 네이버 카페·블로그 후기, 디시·클리앙·에펨코리아 등 해당 주제 커뮤니티의 표현
- [ ] 뉴스·보도자료: 업계 매체와 기자, 보도된 각도
- [ ] 인플루언서·크리에이터: 해당 주제에서 실제 영향력 있는 계정과 대략적 협업 단가 공개 정보
- [ ] 표시·광고 규정 원문: 표시광고법, 추천·보증 심사지침(대가성 표시 문구 규정)

## 5. 작업 지침

### 5.1 브랜드 보이스

톤을 형용사 3개로 고정한다(예: 명료한, 실용적인, 과장 없는). 각 형용사마다 다음을 적는다.

- 이런 문장은 쓴다(예시 1개).
- 이런 문장은 쓰지 않는다(예시 1개).

추가로 금지 표현 목록을 만든다: 최고, 1위, 100% 보장, 무조건, 완치, 절대 같은 단정 표현은 근거 없이 쓰지 않는다(표시광고법 위반 위험). 문장 규칙도 정한다: 평균 문장 길이, 존댓말 형태, 이모지 사용 여부, 영어 단어 허용 범위.

### 5.2 콘텐츠 필러

콘텐츠 주제를 3~4개 필러로 나눈다. 필러는 제품 기능이 아니라 고객의 관심사로 나눈다.

- 예: (1) 문제 인식형, (2) 방법·튜토리얼형, (3) 사례·후기형, (4) 업계 관점형.
- 각 필러에 목적(인지/고려/전환), 주 채널, 발행 비중을 배정한다. 전환형 콘텐츠 비중이 40%를 넘으면 채널이 광고판이 된다.
- 필러별로 첫 달 콘텐츠 제목 3개씩을 실제 제목 문장으로 적는다.

### 5.3 SEO 키워드 클러스터

1. 씨앗 키워드 5~10개를 고객 언어로 뽑는다(제품명이 아니라 문제 표현).
2. 네이버 키워드도구와 구글 키워드플래너로 검색량을 붙인다. 네이버는 PC·모바일을 합산하고 출처와 조회 시점을 적는다.
3. 검색 의도로 묶는다: 정보형(무엇/왜), 방법형(어떻게), 비교형(A vs B), 거래형(가격/신청).
4. 클러스터마다 기둥 글(pillar) 1개와 위성 글 3~5개를 배치하고 내부 링크 구조를 정한다.
5. 우선순위 = 검색량 × 전환 근접도 ÷ 경쟁도. 초기에는 월 검색량 100~1,000의 롱테일을 먼저 잡는다. 대형 키워드는 6개월 뒤 과제로 둔다.
6. 각 글에 목표 키워드 1개, 제목(30자 내외), 메타 설명(80자 내외), H2 구조를 미리 정한다.

### 5.4 채널별 포맷

채널마다 잘 되는 형식이 다르다. 같은 원고를 그대로 복사하지 않는다.

| 채널 | 포맷 | 길이·규격 | 발행 리듬 | 성과 지표 |
|---|---|---|---|---|
| 네이버 블로그 | 문제 해결형 글, 이미지 다수 | 1,500자 이상 | 주 2회 | 유입, 체류시간 |
| 자사 블로그 | 검색 타깃 글, 내부 링크 | 2,000자 내외 | 주 1회 | 검색 유입, 전환 |
| 인스타그램 | 캐러셀, 릴스 | 1080x1350, 릴스 15~30초 | 주 3회 | 저장, 프로필 방문 |
| 유튜브 | 튜토리얼, 쇼츠 | 쇼츠 45초 이하 | 주 1회 | 시청 지속률, 구독 전환 |
| 뉴스레터 | 큐레이션 + 관점 | 800~1,200자 | 격주 | 오픈율, 클릭률 |
| 커뮤니티 | 정보 공유형 참여 | 홍보 티 없는 실사용 정보 | 상시 | 반응, 유입 |

### 5.5 런칭 캠페인 구조

- 사전(2~4주): 대기 명단, 문제 인식 콘텐츠, 베타 모집.
- 출시(1주): 랜딩 공개, 핵심 메시지 1개, 채널 동시 발행, 커뮤니티 공유.
- 이후(4주): 사용 사례, 후기, FAQ 대응, 재방문 이메일 시퀀스.
- 메시지는 하나로 고정한다. 채널마다 다른 약속을 하면 브랜드가 흩어진다.

### 5.6 품질 기준

- 모든 검색량 수치에 출처 도구와 조회 시점이 붙는다.
- 콘텐츠 제목은 실제 발행 가능한 문장이다. "블로그 글 1"처럼 두지 않는다.
- 각 콘텐츠에 목표 지표와 행동 유도(CTA)가 있다.
- 카피는 기능이 아니라 결과를 말한다("자동 정리 기능" 대신 "정리에 쓰던 20분을 줄인다").
- 근거 없는 수치·최상급 표현이 없다.
- 제작 가능한 분량인지 리소스와 대조한다. 주 5편 계획은 1인 팀에서 지켜지지 않는다.

### 5.7 흔한 실수

- 채널을 다 하겠다고 벌리고 어디도 채우지 못한다. 초기에는 2개 채널로 좁힌다.
- 검색량만 보고 대형 키워드를 노려 6개월간 노출이 없다.
- 제품 자랑만 쓴다. 고객 문제 언어가 없으면 검색에도 안 잡힌다.
- SEO 글을 키워드 반복으로 채운다. 검색 엔진과 사람 모두에게 손해다.
- 커뮤니티에 홍보 글을 올려 차단당한다. 정보 제공이 먼저다.
- 후기·협찬 콘텐츠에 대가성 표시를 빠뜨린다.

### 5.8 윤리·법적 주의

- 표시광고법: 객관적 근거 없는 최상급·단정 표현(최고, 1위, 100%)을 쓰지 않는다. 쓰려면 근거 출처를 함께 표기한다.
- 추천·보증 심사지침: 협찬·대가를 받은 후기는 "협찬받았습니다", "유료 광고 포함"처럼 소비자가 쉽게 인식할 위치에 표시한다. 본문 하단 흐린 글씨는 미흡으로 본다.
- 자사 직원이나 지인의 후기를 일반 소비자 후기처럼 게시하지 않는다.
- 비교 광고는 사실에 근거하고 비교 시점·조건을 명시한다.
- 이메일·문자 발송은 사전 동의와 수신거부 경로를 갖춘 뒤에만 한다. 야간(21시~08시) 광고 전송은 별도 동의가 필요하다.
- 의료·건강·금융·교육 분야는 별도 심의·표현 제한이 있다. 해당하면 전문가팀 검토를 요청하고 원고에 "심의 확인 필요"를 표기한다.
- 타인의 이미지·음악·폰트를 라이선스 확인 없이 쓰지 않는다.
