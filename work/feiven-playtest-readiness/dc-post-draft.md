■ 이게 뭔가요
FEIVEN은 개발 중인 3대3 온라인 대전 게임(언리얼 엔진 5)입니다. Windows용 공개 플레이테스트 중이고, 버그와 밸런스 피드백을 받으려고 합니다. 무료이고 가입 외 필요한 건 없습니다.

■ 다운로드 (PC에서 받으세요, 폰으로 받으면 실행 안 됩니다)
https://github.com/hsdc1258/feiven-playtest/releases/tag/r20.1-playtest
- 받을 파일: FEIVEN-Playtest-Setup.exe (약 302 MB, 설치파일 하나, 압축 해제 없음, 설치 후 약 435 MB)
- 같은 페이지의 Source code (zip) 는 게임 아님. 받지 마세요.
- 다른 데 올라온 파일은 공식 아님. 쓰려면 아래 해시 꼭 비교.
- 예전에 R20 받은 분: 같은 파일이라 다시 안 받아도 됩니다. R19는 서버 접속 안 되니 지우고 새로 설치.

■ 설치할 때 경고 뜨는 게 정상입니다 (코드서명 아직 없음)
1) 브라우저에서 "일반적으로 다운로드되지 않는 파일" → Edge는 … → 유지 → 자세히 표시 → 그래도 유지
2) 실행하면 "Windows의 PC 보호" 창 → "추가 정보" → "실행"
3) 관리자 권한(UAC) 창은 안 뜹니다. 내 계정 폴더(%LOCALAPPDATA%\Programs\FEIVEN)에만 설치됨. 관리자 권한 달라는 파일은 공식 아님.
4) 첫 온라인 매칭 때 Windows 방화벽 창 뜨면 "액세스 허용"
※ 백신 끄거나 예외 추가하지 마세요. 해시만 맞으면 됩니다. 백신이 막으면 백신 이름이랑 탐지명 알려주세요.
※ 작업 관리자에 GroundedPVP.exe 로 보이는 건 내부 프로젝트 이름이라 정상입니다.

■ 지원 환경
- Windows 10 1809(빌드 17763) 이상 / Windows 11, 64비트 전용. Win7/8.1 설치 안 됨.
- 32비트, ARM(스냅드래곤) 윈도우는 설치는 되는데 실행이 안 됩니다. 깔지 마세요.
- DirectX 11 지원 그래픽카드. 기본은 창 모드 1280x720.
- 최소 사양: <<운영자 기입>> / 권장: <<운영자 기입>>

■ 시작하는 법
1) 바탕화면 FEIVEN 실행
2) 조작 익히기: "로컬 훈련" (로그인 필요 없음)
3) 온라인: "계정" 메뉴 → Google 로그인 또는 "기존 계정 로그인" (신규 가입도 이 버튼 → 브라우저에서 "회원가입" 탭)
   ※ 브라우저에 뜨는 로그인 페이지 주소는 feiven.teniv.kr 입니다. 다른 주소면 아이디/비번 넣지 마세요.
   ※ 아이디/비번 방식은 비밀번호 찾기가 없습니다. 비번 꼭 기억하세요. Google 로그인: <<운영자 기입: 제공 / 미제공>>
4) "어둠의 성채" 선택 → "준비" 누르면 3대3 매칭. 파티로 들어가면 같은 팀.
5) 음성 채팅은 푸시 투 토크(누르는 동안만). 안 써도 됩니다.

■ 서버 여는 시간 (중요)
<<운영자 기입: 기간 / 매일 HH:MM–HH:MM KST / 서버 지역>>
이 시간 밖에는 로컬 훈련만 됩니다.

■ 서버 작습니다. 미리 양해 부탁드립니다
- 동시 경기 3개 × 6명 = 동시 플레이 18명
- 대기열 최대 48명. 자리 나면 자동 입장, 대기 취소 가능
- 대기열까지 꽉 차면 "<<운영자 기입: 게임 내 문구>>" 뜨고 못 들어갑니다. 그러면 1~2분 뒤 "준비" 다시 눌러주세요. 연타는 소용없고 남들도 느려집니다.
- 한 판은 대략 <<운영자 기입: 평균 경기 시간>>. 끝날 때마다 6자리 비고 순서대로 들어갑니다.
- 기다리는 동안 로컬 훈련 돌리고 계시면 첫 판이 편합니다.
- PC방/회사에서 접속 안 되면 방화벽이 게임 통신(UDP 17777 나가는 방향)을 막는지 확인.

- 지우려면 설정 → 앱 → "FEIVEN Playtest" 제거. 저장 데이터는 %LOCALAPPDATA%\GroundedPVP\Saved 에 남으니 완전 삭제하려면 그 폴더도 지우세요.
