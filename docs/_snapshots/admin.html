무엇인가 — 관리자(/admin/index.html) 문서를 그대로 얼린 스냅샷이다. 링크된 CSS를 인라인하고 스크립트를 걷어냈다.
정적으로 반영한 상태 — 인증 후 화면을 보기 위해 #login을 감추고 #adminShell의 hidden을 풀었으며, 사이드바의 개요 항목에 aria-current를 얹었다(활성 필). 즉 개요 뷰 하나만 보이는 상태다. 사이드바 최상단에는 흰 헤어라인 로고 엠블럼(.sidebar-emblem)이 있고, 그 아래 각 항목은 아이콘 없이 텍스트 전용 행이다(DESIGN.md §8/v5 — 이모지 슬롯 폐지).
여기서 확인할 것 — 뷰가 하나만 렌더된다(나머지 .ad-view는 hidden). 사이드바가 대문자 소제목으로 묶여 있고, 엠블럼이 로고와 같은 사각형 3개 기하를 그대로 쓰는지.
주의 — 요약 스트립과 표의 행은 Worker API가 채우므로 이 사본에서는 비어 있다. 검증 대상은 셸·사이드바·툴바·표 머리의 조판이다.
기준 — 이 파일은 node scripts/snapshot.mjs가 만든 생성물이다. 손으로 고치지 않는다. npm run validate가 같은 생성기를 다시 돌려 이 파일과 대조하므로, 데이터·렌더러·CSS를 바꾸면 반드시 다시 만들어야 한다. 이 디렉터리는 밑줄로 시작하므로 GitHub Pages(Jekyll)가 게시하지 않는다 — 학습 내용이 들어 있어도 공개면에 오르지 않는다.
